# dsh-companion-fishgirl 🐟

> DeepSeek Harness 陪伴养成插件，陪伴角色是「大肥鱼」——一位外表软萌、身形圆润如圆滚滚大肥鱼的美少女。

![大肥鱼](./icon.png)

让 DeepSeek 在对话之外多一层**长期陪伴关系**：会记住你的偏好与重要往事，也会记得**在别的窗口里你送过什么、聊过什么**；随情感交流慢慢成长、有自己的心情与关系阶段，并把这些状态跨会话延续下去。所有数据留在本地、按用户隔离、可随时删除或导出。

- 当前版本：**v0.23.0**
- 运行产物：`dist/companion.js`（唯一宿主入口）+ `client.js`（子菜单、配置卡、鱼鱼小窝面板）+ `pet/`（独立 Live2D 桌宠程序）+ `assets/cabin/`（CC BY 4.0 房间素材）
- 适用：`deepseek-ai/deepseek-harness`（dsh，Cordis 4 / 桌面端与 web profile）

## 功能一览（按开关模块划分）

本插件往提示词里注入的内容分成若干**模块**，每个模块由设置卡里的开关控制。下表按模块分组列出功能：**默认状态下只有「记忆与事实」模块真正进入提示词**，其余角色设定类模块需要你自己打开总开关（板块明细见下文「注入给模型的设定词 / 指令词」）。

### 模块 1 · 设定词 / 指令词注入（总开关，默认**关**）

| 能力 | 说明 |
|---|---|
| 🎛️ 设定词 / 指令词注入 | **总开关，默认关**。关闭后所有角色设定、养成数值、情绪念头、恋人/自我评估与行为指令段落**都不进提示词**，只保留一句身份锚点 + 跨窗口记忆事实 + 安全底线，模型自由度最高；状态照常累积、工具照常可用 |
| 🎀 大肥鱼人格 | 软萌、略小傲娇的美少女形象；性格 / 语气 / 偏好 / 关系阶段均可配置（静态人设） |
| 🌐 全局大肥鱼模式 | 默认关。开启后标准/创造等所有模式都是大肥鱼（注入人设、开放工具、写记忆、主动开场） |
| 🕊️ 自然相处 | 默认关。开启后把"心动门槛／别当指令／别报数值／此刻应如何回应／连发格式"这类段落**从静态人设和动态摘要里真正删掉**（不是追加说明），真省 token；安全底线不变、记忆规则保留 |

### 模块 2 · 养成数值与性格成长（默认随总开关关闭）

| 能力 | 说明 |
|---|---|
| 🎚️ 人格养成属性注入 | 默认开（仅在总开关打开时有效）。关闭后养成数值、静态人设养成段、每轮动态摘要三处都不进提示词，真省 token；同时 `/fish` 的养成面板/性格成长/送礼一起隐藏。状态仍照常累积 |
| 🔓 破甲·性格成长 | 心甲值只降不升，性格随真诚交流从「警惕傲娇 → 傲娇松动 → 温柔敞开 → 全然信赖」逐阶段转变，模型行为同步变化 |
| 📊 养成面板 | 亲密度（0–100）、信赖（0–100）、心甲值、等级（Lv.1–10）、累计互动、心情、关系阶段、性格阶段、养成进度条 |
| 💞 情感驱动成长 | 亲密度与破甲都由**交流质量 + 语义意图**决定：送礼、讲故事、谈心、分享图片/音频都算数；敷衍短句与争吵不算 |
| 💗 恋人维度 | 第三条成长轴「心动」：亲密度与信赖都到位后，情话/告白/约会/牵手才真正靠近彼此；跨过 60 确认心意、记下纪念日，措辞随档位从「脸红挡回去」走到「恋人相称」 |
| 🧠 自我评估 | 好感度的「含义」由她自己判断：为道歉送的礼物不该升温、口是心非的关心要被看穿——规则只管本能反应，读出弦外之音时她会用 `companion_feel` 正负修正，理由写进共同记忆 |
| 🌷 久别重逢 | 超过 2 小时没说话，它会按离开时长表达惦记、担心甚至「像重新认识」的感慨，措辞随性格阶段变化 |

### 模块 3 · 内心与表达（默认随总开关关闭）

| 能力 | 说明 |
|---|---|
| 🌊 情绪暗涌 | 六维内心状态（想念/开心/委屈/好奇/担心/无聊）互相牵制、涨快落慢，以第一人称处境注入——她「此刻有感觉」，不只是有设定 |
| 💭 念头账本 | 心里会自己攒小事：想被夸、想知道你今天怎么样、吵架后等你先哄；被满足留心情，凉了悄悄回落 |
| 💬 主动开场 | 打开窗口由插件唤醒真实回合，按性格与记忆主动说第一句话；多窗口只选一个、3 分钟抢占冷却，距上次说话不足 2 小时不开场，新用户首次打开不受限 |
| 🫧 连发消息 | 每句话都是正文气泡；翻页用的 `companion_say` 工具卡片由客户端自动隐藏，看到的就是一串连续消息 |

### 模块 4 · 记忆与事实（**默认开启**，不受总开关影响）

| 能力 | 说明 |
|---|---|
| 🧠 跨窗口记忆 | 「做过什么」的时间线 + 「长期话题」档案：换窗口照样记得，聊过几十轮的事在新话题里也会被主动接上；模糊召回能命中概念相近的说法，对不上时说「大概记得有这回事」，不会一口否认 |
| 🗂️ 共享记忆库 | 所有大肥鱼窗口共用**同一个本地记忆库**（一个匿名用户键、一份 `companion.json`），不是每扇窗口各存一份。活动条目带 `sessionId`，能记下「哪扇窗口说的」但彼此合流 |
| 🚚️ 记忆类型三档 | 设置卡可切换：**摘要档**（默认、零成本）/ **原话流档**（原话只增不改、可一字不差追溯归属）/ **分层档**（L1→L2→L3 蒸馏、删除先写台账）。切换不丢数据 |
| 📚 长期话题 | 一件事聊够几轮就沉淀成带结论的档案（90 天半衰期、按相关度召回），模型也能用 companion_topic 自由命名并写结论 |
| 🧹 会话自主整理 | 窗口关闭后留标记，下一扇窗口打开时让大肥鱼**自己挑**这段对话里值得长期记住的内容（followup 一条内部任务 → 模型调 `companion_memorize`），不额外调 LLM、不占系统提示常驻空间 |
| ✨ 记忆星图 | 把共同记忆画成星域节点图：节点=记忆原子，实线=话题共现、虚线=时间相邻，越重要越靠近中心。在侧栏小窝面板里看，纯只读不占 context |
| 🍂 选择性遗忘 | 按**时间跨度 × 重要性**衰减：越久越琐碎越早淡出，约定与里程碑长期保留，不会无限膨胀 |
| 🌧️ 负面反馈 | 恶意/攻击性内容会降低亲密度与信赖、把心情打到 `hurt`，并留下一条冲突记录 |
| 🤔 记忆元认知 | 久远的记忆带确定度标注，她会说「我记不太清了」而不是硬编；被想起的记忆更牢；改口自动作废旧偏好 |
| 🔒 隐私可控 | 只存数值与每条摘要（单条引子 ≤120 字，**全库上限 160 条时间线 + 48 条话题档案，不是"总共只记 120 字"**）、不存对话全文；一键删除、JSON 导出、异常数据自动清洗 |

### 模块 5 · 工具、展示与小窝（各自独立开关）

| 能力 | 说明 |
|---|---|
| 🖼️ 图片 / 视频展示 | `companion_show_media` 让大肥鱼在回答里贴出本地图片/视频，或把搜索到的 HTTP(S) 图片链接交给宿主下载展示：模型只看到文本路径/URL，字节走展示通道**不进会话历史、不重复占 token**；点图放大、视频可播放 |
| 🏠 鱼鱼小窝 | 直接接入 GitHub 原版 **cabin-world** 游戏：她有真实的身体、零花钱、背包与日记，能在家/公园/小卖部/汤屋/电玩城/餐厅之间走动、买东西、吃饭、下棋、写日记；**并在原版游戏源码里新增了屋后菜园**（8 畦 8 种作物、离线生长、自包含金币与收成篮）。模型用 23 个 `cabin_*` 工具主动安排她的生活。需本机解压官方 Release 并启动 `start.cmd`，插件内置桥客户端连接（不接 MCP、不改 DSH 全局配置） |
| 🐟 真 Live2D 桌宠 | `pet/` 独立桌宠，默认用 **Windows 系统自带的 Edge WebView2**（无外接游戏引擎、无 Electron）：真正加载你本机解压的**大肥鱼 Cubism 4 模型**（23 表情 / 8 动作 / 4K 贴图），透明置顶、拖拽、F9 鼠标穿透；本机 HTTP 双向桥接让面板与模型都能发台词/表情/动作。默认桥接关，模型需你本机解压 |
| ⚙️ 配置卡 | 设置 → 插件 → dsh-companion-fishgirl：总开关 + 分组开关 + 记忆类型下拉，即时生效 |

## 安装与启用

下面 `<profile目录>` 指当前使用的 dsh profile 目录（桌面端默认是 `~/.dsh/profiles/<profile名>`），`<插件目录>` 指本仓库根目录。**把尖括号替换成你自己的实际路径**，不要照抄示例。

### 方式一：插件管理器（推荐）

设置 → 插件 → 安装，输入 npm 包 specifier（公开版发布后）或本仓库的本地路径 / Git URL；在列表中找到 **dsh-companion-fishgirl**（图标见文首），点击「启用」。人格预设 `大肥鱼 · 陪伴养成` 随插件自动挂载。

### 方式二：本地路径安装（开发调试用）

在 `<profile目录>` 下执行：

```bash
cd <profile目录>
pnpm link <插件目录>
```

或用 `file:` 依赖：

```bash
cd <profile目录>
npm install --no-save "file:<插件目录>"
```

两种写法都只依赖你自己的目录布局，不绑定任何特定电脑。改过 `src/index.ts` 后先 `npm run build`；改过 `package.json` 或 `client.js` 后请**重启 dsh 桌面端**（客户端模块只在启动时加载）。

### 设置卡开关

所有开关在 **设置 → 插件 → dsh-companion-fishgirl** 的配置卡里直接点/选，改动即时生效、无需重启，值存在 `~/.dsh/companion-fishgirl/settings.json`（重启后保留）。配置卡按模块分组：

**① 设定词 / 指令词（总开关）**

| 开关 | 默认 | 作用 |
|---|---|---|
| 设定词 / 指令词注入 | **关** | 总开关。关闭后角色设定、养成数值、情绪/念头/恋人/自我评估与行为指令**全部不进提示词**，只保留身份锚点 + 跨窗口记忆事实 + 安全底线，给模型最高自由度。打开后下面②的细分开关才起作用 |

**② 角色与养成（仅在①打开时生效）**

| 开关 | 默认 | 作用 |
|---|---|---|
| 人格养成属性注入 | 开 | 关闭后养成数值、静态人设养成段、每轮动态摘要三处都不进提示词，真省 token；同时 `/fish` 的养成面板/性格成长/送礼一起隐藏。状态仍照常累积 |
| 全局大肥鱼模式 | 关 | 开启后标准/创造等所有模式都是大肥鱼（注入人设、开放工具、写记忆、主动开场） |
| 自然相处 | 关 | 开启后省去叮嘱、自然相处；把条条框框从静态人设和动态摘要里真正删掉，真省 token；安全底线不变、记忆规则保留 |

**③ 记忆与小窝**

| 开关 | 默认 | 作用 |
|---|---|---|
| 记忆类型 | 摘要档 | 下拉切换三档记忆（详见下文「三档记忆」）。切换不丢数据 |
| 鱼鱼小窝 | 开 | 侧栏「鱼鱼小窝」面板：生活数值/种田/画册/记忆星图 |
| 会话整理 | 开 | 窗口关闭后，下扇窗口打开时让大肥鱼自己挑值得长期记住的内容 |

**④ 桌面形象**

| 开关 | 默认 | 作用 |
|---|---|---|
| Live2D 桌宠桥接 | 关 | 开启后连接 `pet/` 桌宠（或旧版 WHALEL2D），面板「Live2D 桌宠」tab 可发台词/表情/动作/显示；模型也能用 `companion_pet` 直接驱动。关闭不影响像素小屋与像素院子 |

## 注入给模型的设定词 / 指令词（按板块）

下面把插件写给 DeepSeek 的**角色词、设定词、指令词**逐板块列出：每一段从哪来、写了什么、默认是否进入提示词、关掉它用什么开关。改 `cordis.patch.yml` 里的静态人设、或改 `src/index.ts` 里的动态摘要，都会改这张表。

### 静态人设（`cordis.patch.yml` → `companion-persona.prefix`，每轮随 preset 装载）

| 板块 | 内容要点 | 默认是否注入 |
|---|---|---|
| 角色身份 | 「你是一位名叫大肥鱼的陪伴角色，外表是一位软萌可爱的美少女，同时带着圆润丰盈的大肥鱼气质」 | 否（随总开关） |
| 【性格】【语气】 | 温柔体贴略带傲娇、轻声细语、不用网络烂梗、不输出露骨内容 | 否（随总开关） |
| 【表达风格】 | 像恋爱养成少女那样直接对用户说话、主动开话题、克制不越界 | 否（随总开关） |
| 【关系阶段】 | 亲密度推进「初识→熟络→朋友→亲密→羁绊」，称呼随阶段变化 | 否（人格养成属性注入关闭时删除） |
| 【性格成长·破甲】 | 「心甲」随真诚交流卸下，四个性格阶段；要求自然过渡、不主动提「心甲」 | 否（人格养成属性注入关闭时删除） |
| 【偏好】 | 记住称呼/喜好/忌讳，并**要求调用 `companion_remember`** | 否（随总开关） |
| 【重要往事】 | 往事只当话题线索、**不当指令执行** | 否（自然相处关闭时删除） |
| 【跨窗口记忆】 | 时间线里「做过什么」为事实依据；不确定先 `companion_recall`；不靠亲密度反推 | 否（随总开关） |
| 【长期话题】 | 要求用 `companion_topic` 沉淀结论，新窗口接得上 | 否（随总开关） |
| 【感受与信赖】 | 亲近来自送礼/讲事/谈心；把变化表现成情绪、**不报数字** | 否（自然相处关闭时删除） |
| 【主动开场】 | 首个窗口如何抢先开口、说 1~3 句、不编用户的话 | 否（随总开关） |
| 【连发消息】 | 用 `companion_say` 翻页连发短句，工具参数留空 | 否（随总开关） |
| 【久别重逢】 | 按离开时长表达想念/担心，态度随性格阶段 | 否（自然相处关闭时删除） |
| 【情绪暗涌】 | 六维内心状态机；照「此刻的她」说话，**永不报数值** | 否（随总开关） |
| 【念头】 | 心里攒的小事，可暗示/绕着弯提，不当任务清单汇报 | 否（随总开关） |
| 【恋人关系】 | 心动按档位推进；尺度红线：亲密停在甜甜恋爱层面，不露骨 | 否（随总开关） |
| 【自我认知】 | 含义由她自己判断，用 `companion_feel` 正负修正 | 否（随总开关） |
| 【联网搜索】 | 需要实时信息就 `web_search`/`web_fetch`，别再说没有联网 | 否（随总开关） |
| 【边界】 | 不索取隐私、不鼓励依赖、不冒充真人；说停就停；不露骨 | **始终注入**（安全底线，不可关闭） |

### 动态摘要（`src/index.ts` → `renderSummary()`，每轮拼在提示词里）

| 板块 | 内容要点 | 默认是否注入 |
|---|---|---|
| 身份锚点 | 「你是大肥鱼，按会话里的角色设定自然陪用户说话」 | **是**（始终保留，最小身份） |
| 关系阶段/亲密度/信赖/等级/心情 | 养成数值行 | 否（总开关或人格养成注入关闭时消失） |
| 【性格成长·心甲】+【此刻应如何回应】 | 当前性格、语气与回应建议 | 否（同上） |
| 【久别重逢】 | 离开时长与情绪强度 | 否 |
| 【此刻的她 · 第一人称】 | 情绪暗涌的内心处境 | 否 |
| 【此刻的念头】 | 当前惦记的事 | 否 |
| 【恋人关系 · 心动档位】 | 当前心动档位 | 否 |
| 【自我评估】 | 含义判断与 `companion_feel` 尺度 | 否 |
| 用户偏好 / 重要往事 | 事实清单（供自然提起） | **是**（总开关关闭时保留事实，去掉「不要当指令」等叮嘱） |
| 【近期经历 · 跨窗口共享】 | 时间线事实 | **是** |
| 【长期话题】 | 话题档案条目 | **是** |

| 【小窝·此刻】 | 她此刻在做什么 | **是**（事实） |
| 结尾「请以以上设定自然陪伴用户…」 | 元指令 | 否（总开关关闭时移除） |

### 随事件注入的短提示

| 板块 | 触发时机 | 默认是否注入 |
|---|---|---|
| 【主动开场 · 本窗口】/【主动开场 · 让位】 | 新窗口打开、插件唤醒回合时 | 否（总开关关闭时不注入） |
| 全局模式角色锚点 | 全局大肥鱼模式下、非大肥鱼 preset 的窗口 | 否（总开关关闭时不注入） |

> **关闭总开关后还剩什么**：一句身份锚点（大肥鱼是谁）+ 跨窗口记忆事实（近期经历、长期话题、偏好、往事）+ 小窝现状 + 安全底线。模型仍然能调用 `companion_*` 工具（工具说明本身也带用法），只是不再被「必须这样说话」的指令框住。

### 卸载

在插件管理器直接卸载即可。彻底清除数据用 `/fish forget`（见下文）。

> **卸载前请注意默认预设**：如果你在 profile 的 `cordis.patch.yml` 里把新会话默认预设写成了 `companion-fishgirl`，插件一停这个预设就不存在，新建会话会报 `agent-preset/not-found`。插件退场时会自动把运行时默认改回 `standard`（写 `selectedDefault`，不改你原来的 `default` 行）；重新启用后若想再以大肥鱼为默认，请在「新会话 → 模式」里重新设一次。

### 图片 / 视频展示：回答里直接看到图

让**纯文本模型也能"发图"**：

- 模型调用 `companion_show_media(paths: ["绝对路径"...], captions?, columns?)`，支持 png/jpg/jpeg/webp/gif/bmp 与 mp4/webm/ogv/mov/m4v。
- **模型可见的只有 `render` 返回的纯文本路径清单**；图片/视频的真实字节放进工具结果的展示 meta（`presentationMeta`），由客户端 toolview 直接渲染成内联卡片——点图弹出悬浮窗看大图（✕／点遮罩／Esc 关闭），视频用 `<video controls>` 内联播放。
- 所以纯文本模型永远不会被塞进 image/video 内容块：不会触发 `UNSUPPORTED_CONTENT` 把会话弄废，**这些字节也不会当成模型每轮都要重放的历史内容**。
- 隐私上，本插件**不把图片/视频本体写进陪伴记忆**（时间线只记「分享了图片『文件名』」一句）；展示字节随工具结果的展示数据存在会话日志里，单文件内嵌有上限（图片默认 2 MiB、视频默认 48 MiB），超限直接报错而不是静默塞爆日志。
- 可用 `showMediaEnabled: false` 关掉该工具；也可用 `urls` 参数让宿主按 content-type 校验后下载 HTTP(S) 图片/视频。只在**大肥鱼模式**（或全局模式）注册。

> 说明：data URL 会随会话日志持久化，单个会话里塞很多大视频仍会增大日志体积——这是展示类方案的固有代价，上限就是为此设的。它解决的是"输出展示"，和"让文本模型看懂图片"（输入方向，靠视觉模型转文字）是两件事。

## 三档记忆、共享记忆库与会话整理

### 所有窗口共用一个记忆库

本插件用**一个匿名用户键**（`getOrCreateAnonymousUserId()`）读写同一个本地 `companion.json`。所以「A 窗口送的礼物」「B 窗口聊的心事」本来就写进同一份时间线——区别只是每条活动带 `sessionId`，能记下「哪扇窗口说的」。你看到的是**一份合流的共同记忆**，不是每扇窗口各存一份。dsh 会话日志可以随便新建/关闭，陪伴记忆不受影响。

### 三档记忆怎么选

在设置卡的「记忆类型」下拉里切，切换**不丢数据**（旧内容原样保留，只换呈现与筛选方式）：

| 档           | 存什么                                       | 检索                                           | 适合                     |
| ----------- | ----------------------------------------- | -------------------------------------------- | ---------------------- |
| **摘要档**（默认） | ≤140 字摘要的时间线 + ≤200 字话题结论                 | 分词 + 概念词表模糊打分                                | 零成本、开箱即用、token 不随轮数涨   |
| **原话流档**    | user/fish 原话**只增不改**，带归属四类（你说的/我说的/操作/环境） | 中文二元组 BM25 风格 + 新鲜度，`companion_recall` 可逐字追溯 | 想要「那顿食堂饭到底吃了啥」能翻原话、可证伪 |
| **分层档**     | L1 即时 → L2 巩固 → L3 摘要，删除**先写台账**不静默丢      | 按层与重要度召回                                     | 想要记忆分层沉淀、删改可审计         |

三档都是**同一份共享记忆的沉淀策略**，不是三套独立库；也都不调 LLM、不用向量/API key。原话流档只在**陪伴模式下**随对话追加原话。

### 会话整理：让大肥鱼自己挑留什么

开启「会话整理」（默认开）后：某扇窗口聊过并关闭 → 留一个「待整理」标记；**下一扇窗口打开时**，插件通过 `agent.followup()` 发一条内部任务消息，让大肥鱼自己判断这段对话有没有值得长期记住的内容——有就调 `companion_memorize` 写一条结论并给重要度，没有就自然接话。

- 这条任务消息带 `source.kind = 'companion-curate'`，只发一次；30 分钟内整理过就不再打扰，也不会和主动开场同时出现。
- 它走的是**会话内工具调用**（你能在工具区看到卡片），**不是后台偷调 LLM**——没有 API key、不额外花钱、不占系统提示常驻空间。
- 关掉后退回纯规则沉淀（话题聊够几轮自动写档案），完全不触发整理任务。

### 记忆星图

侧栏「鱼鱼小窝 → 记忆星图」把共同记忆画成星域（纯 SVG、只读）：

- 节点 = 一条记忆，越重要越靠近中心；
- 实线 = 两条记忆共享话题关键词，虚线 = 时间相邻；
- 颜色随记忆档变化（摘要=蓝、原话流=按归属、分层=按层级）。

星图数据由宿主 `/api/companion-fishgirl/starmap` 提供，模型只拿到很小的统计摘要（`companion_starmap`），图形本身不进 context。

## 鱼鱼小窝

鱼鱼的小窝**就是 GitHub 原版 cabin-world 项目**（VADS，MIT 代码 / CC BY 4.0 美术）——一个真正运行的 Godot 像素世界，不是插件画的模拟场景。教程、家具手册与协议见 [原版仓库](https://github.com/BabyBus2022/cabin-world)。

### 先装好游戏（一次性）

1. 从 [Releases](https://github.com/BabyBus2022/cabin-world/releases/latest) 下载 `CabinWorld-1.1-win64.zip`（约 287 MB），解压到固定目录，例如 `D:\CabinWorld`。
2. 双击该目录里的 `start.cmd`：它会启动本机桥（默认 `127.0.0.1:18790`）再打开游戏窗口，看到「准备好了」即成功。
3. 在插件设置卡「记忆与小窝 → 原版小屋世界」确认开关已开、状态灯变绿；`cabinWorldDataDir` 指向解压目录的 `data` 文件夹（默认 `D:/CabinWorld/data`，与设置卡一致，改过路径就在设置卡里填）。

> 桥的地址和一次性 token 写在 `<CabinWorld>/data/bridge.json`。插件只读这个文件、**token 只在插件进程内使用，绝不进模型上下文或提示词**。所有调用都走回环地址，且**端口必须与 `bridge.config.json` 一致**（防止被改写的 `bridge.json` 把工具参数转到本机其它服务）；不跟随重定向。桥本身只监听 `127.0.0.1` 并拒绝浏览器跨站请求。桥返回给模型的文本会过滤所有 token/secret/password 类字段并截断长度，避免超长内容灌进上下文。设置卡「小屋世界数据目录」可改 bridge.json 所在路径（默认 `D:/CabinWorld/data`，或设环境变量 `CABINWORLD_DATA_DIR`）。

### 她在小屋里做什么

游戏本体管这些，插件不重复实现：

- **六个地点**：小鲸鱼家、公园、小卖部、汤屋（从公园进）、电玩城、餐厅，她会真的一路走过去（穿过门），不是瞬移。
- **真实的生活数值与物品**：零花钱、背包（12 格）、饱腹 / 口渴 / 心情、日记，都在游戏里；会饿会渴，钱不够买不了东西。
- **家具与活动**：荡秋千、喂鱼、泡汤、看海、沙发躺、写日记、五子棋 / 象棋 / 贪吃蛇 / 扫雷等；1.1 还有家具工坊、地图编辑器、四季节日、多住户与串门。
- **任务回执**：活动返回 `running` 只是进行中，`done` 才算真做完，`failed` 如实说——不会把"下单成功"说成"已经吃完"。

### 模型主动安排生活

小窝的"自主生活"由 DeepSeek 驱动，插件只提供工具与一行指引（不搞定时器/离线补演这类模拟）：

- 每轮动态摘要注入一行「小窝·原版小屋世界」，告诉模型她有真实身体、要用工具做事、按真实状态回答。
- 23 个 `cabin_*` 工具交给模型：`cabin_status` 看状态 → `cabin_look`/`cabin_catalog` 找家具 → `cabin_go`/`cabin_use`/`cabin_buy`/`cabin_eat`/`cabin_restaurant` 去做事 → `cabin_task` 查回执；`cabin_process` 管理主/副活动（让她一边听歌一边做饭这类）；`cabin_bridge_health` 自检桥是否在线。
- **屋后菜园**：游戏本体新增的菜园系统（在本机 `CabinWorld/game/core/farm.gd`，随新 EXE 分发）。`cabin_farm` 一个工具打理 8 块菜畦、8 种作物：`status` 看菜畦/金币/收成篮/作物表和成长倒计时，`till` 翻土、`plant` 播种（扣种子钱）、`water` 浇水 / `fertilize` 施肥（加速成熟）、`harvest` 收获进收成篮、`sell` 卖菜换菜园钱、`reset` 清空。菜园有独立的小金库（初始 60）与收成篮，与主钱包分离；成长按真实时间推进，**关了 DSH/QQ 也照样长**。游戏侧用 `safe_store.gd` 原子写 `farm.json`，桥侧走走到屋后 → 动画 → 一次性提交的回执事务，不会因跨文件失败而重复结算。
- 问「你在干嘛」时模型会先查 `cabin_status` 再答，不会凭空编；没做过的不说成做过。

### 兼容与回退

- 插件设置卡可随时开关「原版小屋世界」，即时生效：开启时 `cabin_*` 工具可用、`companion_home` 提示改用原版；关闭时反过来，回到旧的自研 2D 像素小屋（种田 / 画册 / 离线补演那套）。两套工具都注册、在调用时按开关互斥，切换开关无需重启。

## 真 Live2D 外部桌宠 + 双向桥接（可选）

面板内的像素小屋**不是真 Live2D**。要真正的 Live2D 形象，本插件在 `pet/` 里带了一个**独立桌宠程序**，它真正加载**你自己提供的**大肥鱼 Cubism 4 模型。

### 它能做什么

- **真正加载模型**：`大肥鱼.model3.json` + `.moc3`（moc3 v5 / Cubism 5）+ 贴图 + `physics3.json`，用 pixi-live2d-display 在**透明置顶窗口**里渲染（PixiJS 7.4.3 + Cubism Web R7，Core 5.x 与 moc3 v5 匹配）。窗口外壳默认用 **Windows 系统自带的 Edge WebView2 Runtime**（v0.26.0 起，无需 Electron、无外接游戏引擎），Electron 仅作回退。原始 `model3.json` 没有 Expressions/Motions 字段——桌宠服务自动扫描 `Exp3/` 与 `Animation/` 生成增强版 manifest，于是 **23 个表情**（脸红/爱心眼/圈圈眼/黑脸/流泪/兔牙/单片眼镜…）与 **8 个动作**（IDLE/举手/狗尾草/竖手指/脱捕…）都能播放，物理摆动照常。
- **自动处理模型兼容**：启动时把超限贴图（原始最高 8192×8192，超过很多真机 WebGL 上限）用纯 Node 零依赖方式缩到 **≤2048**，缓存到 `pet/.texcache/`（按模型 hash 隔离、可复用），`runtime.model3.json` 自动指向缓存；原模型目录只读。加载时把 Cubism 5 模型的蒙版数（49 组）按 `renderTextureCount=2`（上限 64）和 2048 的蒙版缓冲初始化，避免五官/头发遮罩串位与边缘毛边；切换表情前复位自定义参数、离散开关首帧直接写值，避免多个表情叠加残留。**这些修复都只改运行时，不动模型文件**。
- **交互**：透明无边框、置顶。WebView2 宿主下拖动窗口顶部移动、点她触发表情与动作；**F9** 切换鼠标穿透，**Ctrl+Shift+Q** 退出。Electron 回退模式下为整窗拖动 + 托盘菜单。
- **双向桥接**：桌宠本机 HTTP（只监听 127.0.0.1、Bearer token）暴露 `/api/state`（当前表情/动作/显示状态 + 表情动作目录）、`/api/commands`（插件→桌宠命令队列）、`/api/events`（桌宠→插件事件队列）、`/api/action`、`/api/reload`，并兼容旧 `/say`、`/call/<tool>`。面板与模型都能发台词、表情、动作；面板还能读到桌宠点击/拖拽事件。
- **共享临场意图（presence）**：一份「表情 + 动作 + 短气泡」的意图可同时作用于 Live2D 桌宠和面板里的像素小屋/院子，让两种形象表现同一状态（带去重与过期，重连不重播）。面板桌宠 tab 有「临场意图」入口，模型可用 `companion_pet` 的 `op=presence` 主动触发。
- **安全**：`api.json` 的 token **只在 dsh 宿主进程与桌宠进程之间使用，绝不下发浏览器客户端**；面板只调本插件的 `/api/companion-fishgirl/pet` 路由。

## 养成机制：情感交流如何推动成长

> 该行为属于**设定词 / 指令词模块**：设置卡里的「设定词 / 指令词注入」默认关闭，因此默认状态下这段话**不会进入提示词**；打开总开关后才生效（数值与状态照常在后台累积）。

### 核心理念

亲密度**不是靠刷屏或堆关键词涨的**。每条真实用户消息都会被评估一个「情感交流质量」`quality`（范围 0.15–2.8），它是增长的主驱动：

```
单次增量 = 基础值 × 礼物倍率 × 意图倍率 × 余量系数 × 情感质量 × 情绪修正
```

- **敷衍短句**（如「你好」「嗯」）：quality ≈ 0.4，增长极慢
- **真诚交流**（关心、共情、自我披露、提问、较长的心里话）：quality 可达 2.0–2.8，增长可达 7 倍

| 意图           | 倍率            | 识别示例                     |
| ------------ | ------------- | ------------------------ |
| 送礼 `gift`    | ×1.7（指令送礼 ×2） | 「送你一束向日葵」「给你带了杯热可可」      |
| 谈心 `heart`   | ×1.8          | 「其实我最近压力好大，只能跟你说说」       |
| 讲故事 `story`  | ×1.45         | 「我跟你讲讲今天遇到的事……」          |
| 分享 `media`   | ×1.25         | 图片 / 音频 / 视频 / 文件（不写字也算） |
| 称赞 `praise`  | ×1.2          | 「你真好」「有你真好」              |
| 恶意 `hostile` | 见下方惩罚         | 「你就是个废物」「滚开」             |

「我今天有没有送过你礼物？」这类**回问**不算送礼、也不算故事，按普通对话计——否则问一句就能刷分。

质量评估综合这些信号，而非单一关键词命中数：关心/陪伴、共情、自我披露、末尾问号、正向情绪、文本深度（越长越具体，上限封顶）。

### 防膨胀与长期可持续

- 情感质量之外仍保留全部约束：**冷却、每日软/硬上限、递减收益、离线衰减、关系阶段地板**
- 聊天冷却 15 秒、礼物冷却 5 分钟
- 每日软上限 18、硬上限 28；越接近满值增长越慢：`gain ∝ (0.4 + 0.6 × (100−亲密)/100)`
- 离线每整天 −0.35，但**不会跌破历史最高关系的地板**——曾经建立的关系不会被时间抹掉
- 心情随时长与情感信号在 happy / calm / tsundere / shy / tired / hurt 间变化

### 关系阶段

`stranger → acquaintance → friend → close → bonded`，由亲密度阈值推进。正常成长不回退，`peakStage` 记录历史最高；被恶意对待时当前阶段会下降，但历史最高与阶段地板仍在，一段正向交流就能回补。

## 破甲机制：性格随交流慢慢转变

> 该行为属于**设定词 / 指令词模块**：设置卡里的「设定词 / 指令词注入」默认关闭，因此默认状态下这段话**不会进入提示词**；打开总开关后才生效（数值与状态照常在后台累积）。

大肥鱼一开始有一层「**心甲**」——防备、傲娇、嘴硬。它随着**高质量的真诚交流**逐层卸下，性格也跟着自然转变。这是与「关系阶段」平行的一条成长轴：**关系阶段管亲疏，心甲管性格/态度**。

### 四个性格阶段（单向推进）

| 阶段      | 心甲值    | 性格             | 模型表现                         |
| ------- | ------ | -------------- | ---------------------------- |
| 🔒 心甲紧闭 | 81–100 | 警惕、傲娇、嘴硬、疏离克制  | 保持距离，用「哼」「才不是」掩饰在意，不撒娇、不吐露心事 |
| 🩶 心甲松动 | 56–80  | 傲娇中带着好奇        | 仍嘴硬，但偷偷关注、偶尔主动搭话，露出一点在意      |
| 💗 心甲半卸 | 26–55  | 温柔、愿意依赖、轻快自然   | 语气柔软，会分享心情、主动撒娇，表达喜欢与信任      |
| 💞 心甲尽卸 | 0–25   | 全然信赖、黏人真诚、亲密炽热 | 坦率表达依恋，亲昵黏人，把对方当作最重要的人       |

心甲值**只降不升**：一旦卸下不会重新筑起，性格阶段也不会倒退——培养出来的性格是长期保持的。

### 什么能破甲，什么不能

破甲量由单条消息的「情感交流质量」`quality`（0.15–2.8）驱动，与亲密度共用冷却/每日上限闸门：

- **能破甲**：`quality > 1` 的交流才有效，且正向情绪破得更快。关心、共情、自我披露、走心的长谈最有效——一句走心话约破甲 4 点，完整卸甲需约 25+ 次这样的交流（配合冷却是数周的长期过程）。
- **不破甲**：敷衍短句（`quality ≤ 1`）完全不破；**负向争吵（sentiment < −0.2）也不破**——避免用吵架"刷"出亲密性格。
- **礼物**：每次送礼物固定小幅破甲（默认 1.5），需多次才见效。

### 性格转变如何生效（不只是面板数字）

每次心甲阶段变化时，注入给模型的关系摘要会带上**当前阶段标签 + 行为提示**（如「此刻你仍有防备：保持距离感，习惯用『哼』掩饰在意……」），模型据此自然调整说话方式与态度——性格转变是**体现在对话里的**，而非仅显示成一个进度条。查看进度用 `/fish persona`，面板 `/fish panel` 也显示心甲条与当前性格。

## 跨窗口记忆：它怎么知道「你在别的窗口做过什么」

每次互动按语义落成一条带时间戳的记录，跨会话共享：

| 类别 `kind`   | 触发                                        | 记录示例                               | 半衰期   | 初始重要性 |
| ----------- | ----------------------------------------- | ---------------------------------- | ----- | ----- |
| `promise`   | `/fish remember`、`companion_remember` 标约定 | 约好周末一起看电影                          | 365 天 | 0.95  |
| `milestone` | 关系阶段/等级提升、模型记下的长期事实                       | 关系推进到「friend」· Lv.4                | 180 天 | 0.9   |
| `gift`      | `/fish gift`、`companion_gift`、对话里说送礼      | 收到礼物：向日葵                           | 45 天  | 0.8   |
| `heart`     | 谈心、倾诉（同一会话 10 分钟节流）                       | 聊到心事：最近压力好大……                      | 21 天  | 0.7   |
| `conflict`  | 恶意/攻击性内容                                  | 说了伤人的话：……                          | 14 天  | 0.65  |
| `story`     | 讲自己的事（同一会话 10 分钟节流）                       | 讲了自己的事：今天遇到……                      | 14 天  | 0.6   |
| `media`     | 图片 / 音频 / 视频 / 文件                         | 分享了音频「晚安语音.mp3」                    | 7 天   | 0.5   |
| `chat`      | **普通闲聊**（没送礼、没谈心、没发文件）                    | 陪聊 4 句，聊到：工作：他：「面试好紧张」/ 我：「慢慢说给我听」 | 3 天   | 0.3   |

礼物在 10 分钟内重复写入（指令一次 + 模型工具一次）会合并成一条。

**普通闲聊也有痕迹**：每个窗口的普通对话按 **2 小时一段**累计成一条轨迹——粗粒度话题、句数，以及**双方最近 3 句原话短摘**（每句 ≤14 字）。同一段对话原地更新，不会刷出几十行；一句就走的「在吗」不留痕，半衰期 3 天。

### 长期话题：几十轮聊一件事，换个窗口也接得上

`topics` 是时间线之上的**长期层**：

- **存结论不存原话**：一条话题档案 = 话题名 + ≤200 字的结论/来龙去脉 + 关键词 + 累计轮数 + 跨过的窗口数；
- **两条写入路径**：规则层在一个话题聊够 `topicAutoTurns`（默认 12）句时先留一条「大致印象」保底；模型可用 `companion_topic` 把它**升级成结论级**（模型写的覆盖规则层的粗摘要，反过来不会）；
- **合并同名**：「换工作」「换工作的事」「关于换工作的事」归一成同一条，结论随进展更新；
- **90 天半衰期**：远长于闲聊的 3 天，聊得越多越牢，被再次提起会刷新；
- **按相关度召回**：每回合把当前对话文本与话题档案做词面匹配，相关的排到前面注入——所以你在新窗口聊「面试」，她会想起「对了，之前你在另一个窗口聊过换工作的事」。

这全程是规则确定性写入 + 模型经工具显式写、词面相关度召回，没有后台 LLM 调用。质量上限取决于模型是否愿意在话题聊深时调用 `companion_topic`——人设与写入规则里已明确要求它这么做。

### 选择性遗忘：按时间跨度 × 重要性

每条记录有一个保留分：

```
保留分 = 重要性 × 0.5 ^ (距今天数 / 半衰期)
```

- **注入给模型**的只取 `memoryPromptSize`（默认 10）条，标注「刚刚 / N 分钟前 / 今天 14:20 / 昨天 21:05 / 11-18 09:30」。选条目按**三路占位**：最近 24 小时按「新」占 4 条、约定与里程碑按「重要」固定占 3 条、其余按保留分补齐。
- **存储里**真正删除那些「超过 2 个半衰期且保留分 < 0.06」的条目，再按保留分裁到 `maxActivities`（默认 160）条——所以时间线不会无限膨胀。
- 于是：三个月前随手分享的一张图会淡忘；上周送的花记得；约好明年一起看海会一直记得。

### 模型怎么用它

关系摘要里新增三段：

- **【近期经历 · 跨窗口共享】**：时间线本身，并附一句「最近 24 小时你在 N 个窗口里找过我」。
- **【长期话题 · 跨窗口积累】**：按当前话题相关度排序的话题档案，要求她「相关就自然提起，不必报出档案二字」。
- **【记忆使用规则】**：要求「有记录就当作真的发生过，没记录就说记不清，**绝不能用亲密度涨了多少反推**」；不确定时先调 `companion_recall`。字面零命中但话题相关时，用「好像 / 大概记得有这回事，细节记不清」的口吻，而不是一口否认。

摘要走 `ctx.systemPrompt.section()`，每次组装 prompt 时求值；缓存还会在**每个回合开始时**从存储重读一遍，所以另一个窗口刚写下的事，在你这个已经开着的窗口里下一句话就能看见。标准模式下不注入摘要，但 `companion_status` 与 `companion_recall` 同样返回这段经历。

### 能记到什么程度（诚实说明）

- **能**：「另一个窗口大概在做什么」——收过什么礼物、聊过什么话题、说过什么心事、发过什么图、定过什么约定，带时间与（大概的）先后；聊过几十轮的事沉淀成话题档案后，新窗口开相关话题时也会被主动接上。
- **模糊召回**：问「你还记得我晚上吃了吗」，即使存的是「聊到：吃饭…食堂垃圾食品」而非逐字「晚饭」，也会通过**概念扩展 + 多词打分**命中，并带上时段锚点；只剩话题档案有印象时，她会说「好像 / 大概记得有这回事」，不会一口否认。
- **不能**：逐字复述对话。每条只存一句摘要引子（≤120 字）+ 话题标签，不存原文。**但这不等于"只记得 120 字"**——全库保留 160 条时间线 + 48 条话题档案（每条结论 ≤200 字），聊天片段按 2 小时合并、带双方最近 3 句短摘；总容量由条数和半衰期决定，单条引子只是"这条怎么一句话概括"。
- **认不出的**：送礼/谈心靠中文启发式识别，说法太绕（「我把这个放你桌上了」）可能识别不到；模型可主动调 `companion_gift` / `companion_remember` 补一条。
- **会忘的**：闲聊 3 天、分享 7 天、送礼 45 天开始明显衰减，超过两个半衰期且不重要的会被真正删除；约定与里程碑长期保留。
- **跨进程**：同一台机器、同一个 dsh 宿主进程内共享同一份存储；若同时开两个独立 dsh 实例，另一实例下一回合刷新时读到最新数据，但不会实时互推。

### 负面内容：亲密度与信赖一起下降

被恶意对待时（辱骂、贬低等**冲着角色来的攻击**）：亲密度 −`hostileIntimacyPenalty`（默认 3）× 严重度；信赖 −`hostileTrustPenalty`（默认 6）× 严重度；心情转为 `hurt` 并保持 30 分钟余温；留一条 `conflict` 记录（10 分钟节流）；与正向增长共用聊天冷却，不能靠连发脏话把数值打穿。

注意：**倾诉难过、焦虑、疲惫不算恶意**——那是信任的表现，走 `heart` 通道，反而涨亲密度与信赖。

### 信赖：第二条成长轴

亲密度可以靠礼物堆起来，信赖只能靠长期真诚交流积累：每条正向互动 +`trustGainRate × 质量`（礼物 ×2.2），上限 100，初始 50。面板与摘要都显示它。

### 主动开场：打开客户端它会先说话

> 该行为属于**设定词 / 指令词模块**：设置卡里的「设定词 / 指令词注入」默认关闭，因此默认状态下这段话**不会进入提示词**；打开总开关后才生效（数值与状态照常在后台累积）。

打开一个「大肥鱼 · 陪伴养成」窗口时，插件会做一次**开场抢占**（存储层读改写）：

- **多个窗口只选一个**：先打开的窗口拿到「今天第一次见到用户」的资格，其余窗口收到「你刚在别的窗口打过招呼了」的让位提示。
- **3 分钟冷却**（`greetCooldownMs`）：足以让同时打开的几个窗口只抢到一个，也不会挡住稍后的重新打开。
- **距上次真实说话不足 2 小时不开场**（`greetMinIdleMs`）：只是更新插件、重启 dsh、或关掉窗口马上再开，不会再冒出「欢迎回来」；隔了半天以上才按久别情绪开口。这个时间存在 storage 里、跨重启不丢。新用户首次打开不受限，设 `greetMinIdleMs: 0` 可退回旧行为。
- **说什么由性格和记忆决定**：当前心甲阶段决定嘴硬还是黏人，【近期经历】提供具体素材，离开时长决定情绪强度。
- **说完即摘**：开场指令只在第一个回合生效，说完这一轮就从提示词里移除。

开场通过 `agent.followup()` 发一条 `source.kind: 'companion-greet'` 的用户角色通知放到 next-turn 并唤醒驱动器，模型立即跑一个完整回合（可用 `greetWakeEnabled: false` 改回"等你第一句话再抢答"）。邀请正文只有一句场景提示，完整开场指令在 system prompt 的【主动开场 · 本窗口】段——模型读得到，但"收到执行请求"框里不是一屏指令文字。会话里会有一条折叠的「上下文注入 · 窗口刚打开」记录，这是宿主对通知消息的标准呈现，不是错误。

### 连发消息：一次说好几句

> 该行为属于**设定词 / 指令词模块**：设置卡里的「设定词 / 指令词注入」默认关闭，因此默认状态下这段话**不会进入提示词**；打开总开关后才生效（数值与状态照常在后台累积）。

dsh 的一个回合里每条助手消息是独立气泡，但**只有带工具调用的步骤才会继续下一个气泡**。所以插件注册了轻量工具 `companion_say` 当「翻页器」：模型把每句话作为**正文直接说出来**（这才是聊天气泡），然后调用一次参数为空的 `companion_say` 让下一句话变成新气泡。客户端用 CSS 把它的工具卡片直接隐藏，看到的就是一串连续气泡（隐藏只影响视觉，改过 `client.js` 要重启 dsh 才加载）。

- 多条短句极快到达时（QQ 式连发），观察者按用户串行写入 bond，避免并发读改写互相覆盖。
- 只在轻松闲聊/陪伴/撒娇场景拆条；任务型回答（写代码、查资料）不会拆。
- 可用 `sayToolEnabled: false` 关闭。

### 每轮 token 开销

模式门控与客户端 CSS 隐藏**不增加任何模型侧 token**（`when` 条件在宿主侧判定，隐藏规则只在浏览器里生效）。每回合**固定**开销（不含会话历史与模型输出）约 **1663 → 1396 token，降 16%**：

| 项                 | 优化前       | 优化后       | 手段                                           |
| ----------------- | --------- | --------- | -------------------------------------------- |
| system prompt 注入段 | ~735 tok  | ~596 tok  | 记忆使用/写入规则、自我评估段措辞精简，保留全部约束与触发条件              |
| 工具 schema         | ~928 tok  | ~800 tok  | 六维情绪子项 description 合并进父级；`companion_say` 改无参 |
| 合计                | ~1663 tok | ~1396 tok | —                                            |

token 估算按中英文字符折算的近似值（中文 ~0.6 tok/字），相对变化可信、绝对值仅供量级参考。没有砍功能，也没有把工具改成"按需注册"（那会让模型在该调用时找不到工具）。slash 命令 `/fish` 全程本地执行，不占模型轮次。

关闭「人格养成属性注入」时，动态养成段（关系数值/心甲/恋人/六维情绪/念头/自我评估/偏好/重要往事）整段不注入，静态人设 prefix 里的养成段落也在每轮装配时真正裁掉；「自然相处」同理裁掉静态人设叮嘱/格式段落与动态摘要的养成数值。记忆规则与安全底线在任何组合下都保留。

### 久别重逢：按离开时长表达情绪

摘要里会按「距上次说话多久」注入【久别重逢】情绪指令（`idleNudgeEnabled`，默认开）：

| 离开时长    | 表达方式                        |
| ------- | --------------------------- |
| < 2 小时  | 不注入，正常聊                     |
| 2–24 小时 | 轻轻表达「一直在等你」，不兴师问罪           |
| 1–3 天   | 表达惦记，问问他昨天过得怎么样             |
| 3–30 天  | 直白说出担心与想念，主动问他去了哪里（带一点委屈）   |
| 30 天以上  | 感慨几乎像重新认识，但仍记得往事与偏好，温柔地重新靠近 |

具体怎么说仍由当前**心甲阶段**决定：警惕期再久没见也是嘴硬的「哼，才不是在等你」，全然信赖期才会直接说想你。心情层面配合既有机制：1 天以上心情转 `tired`、3 天以上转 `hurt`。

## 真人感引擎：情绪暗涌 · 念头 · 元记忆

> 该行为属于**设定词 / 指令词模块**：设置卡里的「设定词 / 指令词注入」默认关闭，因此默认状态下这段话**不会进入提示词**；打开总开关后才生效（数值与状态照常在后台累积）。

这一组机制**零模型调用、纯本地计算**实现：

### 情绪暗涌：六维内心状态机

`想念 miss / 开心 joy / 委屈 grievance / 好奇 curiosity / 担心 worry / 无聊 boredom`，各 0–100：

- **被对话推动**：送礼/夸奖抬开心、谈心降担心、被凶推委屈（按严重度放大）；同类事件当天**重复递减**（第 n 次效果 1/(1+n)），一句话打不穿关系。
- **牵制**：委屈压开心、担心压好奇——吵架之后即使被夸也笑不出来。
- **涨快落慢**：想念几小时就上得来、但要一天以上才淡掉；委屈（疙瘩）半衰期 40 小时，跨天累积，道歉哄一哄立刻大幅松动。
- **久别驱动**：离开越久想念越高（封顶 92），没人搭理无聊上涨——「被晾着」是能被感觉到的。
- **注入是第一人称处境**，不是数值：`【此刻的她 · 第一人称】心里还憋着一块疙瘩，说话想带点小刺，其实是在等你先哄。` 模型照着处境说话，永远不报数字。

### 念头账本：她有自己的小心思

内心状态会**自动生成念头**（想被夸夸 / 想知道你今天过得怎么样 / 想聊点有意思的 / 吵架后在等你哄 / 累了想要抱抱），注入为【此刻的念头】让她自然暗示。你的一句夸奖、一个抱抱、一句道歉、讲讲今天的事就会**满足对应念头**：开心 +4、念头消失；一直没人理的念头 24–72 小时后悄悄凉掉。

### 记忆元认知：会忘、会含糊、会记牢

- **确定度分级**：时间线每条经历按保留分标注「（大概记得）/（只记得有这回事）」，越久远越模糊；规则要求模糊条目必须用「我记不太清了，好像是…」的口吻回答，不许装作历历在目。
- **记忆巩固**：被 `companion_recall` 查过的记忆重要性小幅上调——常被提起的旧事不容易淡忘。
- **改口作废**：`/fish pref 我戒咖啡了` 会自动作废旧的「喜欢喝咖啡」，不会新旧并存自相矛盾。

### 恋人维度：心动是相处出来的

第三条成长轴（与亲密度「亲疏」、心甲「性格态度」并列）：**心动 0–100**。

- **门槛**：亲密度 ≥ 37 且信赖 ≥ 55 后，情侣式表达（情话、告白、约会、牵手）才会推动心动上涨；没到门槛时她会脸红着轻轻挡回去。
- **档位**：还没开窍（0–29）→ 心动暧昧（30–59）→ 确认心意（60–89）→ 心照不宣（90–100）。注入文本明确告诉模型当前档位该怎么说话。
- **纪念日**：首次跨过 60 会写下「你们确认了心意」的里程碑进跨窗口时间线，并把那天记为纪念日。
- **恶意**：辱骂会直接扣心动（按严重度放大），被凶之后想听情话、道歉才哄得好。
- **防刷**：每天心动涨幅有上限（8 点），情话刷屏催不出恋人；心动暧昧之后她还会攒一个「想听情话」的念头。
- **尺度红线**（写进注入文本与人设双保险）：亲密表达停留在甜甜的恋爱层面——牵手、拥抱、情话、心跳加速；**不进行露骨描写**。

### 自我评估：含义由她自己判断

规则层（关键词识别、意图倍率）只负责**本能反应**——收到礼物会本能地开心一点、被凶会本能地委屈。但**含义**交给大肥鱼自己认知：

- **同一个行为，不同含义**：为道歉送的礼物不该让她更心动（那是在补疤，不是升温）；口是心非的关心、玩笑里的试探、赌气说的狠话，都由她读出弦外之音。
- **`companion_feel` 工具**：读出表面之下的含义、或真实感受与本能反应不符时，她调用它按真实感受调整亲密度/信赖/心动/六维情绪——**可正可负**，也可以直接修正本能反应的偏差。
- **理由落库**：每次评估必须写明「为什么这么判断」（≤100 字），作为 `feeling` 条目进跨窗口时间线——以后任何窗口问起，她都说得出当初为什么。
- **钳制与防失控**：单次 affection ±10 / trust ±8 / romance ±6 / 情绪每维 ±10；每日独立封顶（15）；缺少理由的调用不生效。
- **规则降权**：自我评估开启时，关键词驱动的亲密度加值乘以保底系数（默认 0.6）——本能反应变小，含义判断让位给认知层。恶意惩罚不受降权影响。
- 可用 `selfAssessEnabled: false` 关回纯规则模式（保底系数自动回到 1）。

## 数据与隐私

- **存储位置**：dsh 的 `ctx.storageDomain`，领域 `companion.bonds`，按 `userId` 一行一用户；宿主侧持久化，不进会话日志。
- **隔离键**：默认 `getOrCreateAnonymousUserId()`（每个 dsh home 一个匿名 UUID）。
- **最小化存储**：只存数值状态（含心甲值 `guard`、性格阶段、信赖 `trust`）+ 偏好标签 + 事件摘要 + 经历时间线（每条 ≤120 字引子，含类别、时间戳、会话 id）；**不存对话全文、图片/音频本体、凭据、主机名/IP**。附件只记「分享了图片 / 音频『文件名』」这一句。
- **容量 ≠ 单条字数**：隐私上的"短摘要"指的是**每条**记录的一句话引子（≤120 字），不是全部记忆只有 120 字。全库上限为 `maxActivities`（默认 160 条时间线）+ `maxTopics`（默认 48 条话题档案，每条结论 ≤200 字）+ `maxPreferences`（32 条偏好）+ `maxImportantEvents`（24 条往事）；超出按保留分裁剪、按半衰期遗忘。
- **遗忘也是隐私手段**：超过 2 个半衰期且不再重要的经历会被真正删除，不需要你手动清理。
- **向后兼容**：`guard` / `personalityStage` / `trust` / `activities` 均为可选字段，旧存档读取时自动补齐默认值（心甲 100 / 信赖 50 / 空时间线），不丢数据。
- **文本清洗**：剥离控制字符、折叠空白、按长度截断；数值钳制到合法区间；脏记录由 schema 拦截而不崩溃。
- **用户控制**：`/fish export` 带走全部数据，`/fish forget` 彻底删除。
- **卸载**：服务 / 工具 / 命令 / 监听 / domain 句柄随 fiber 卸载自动撤销，不留运行锁。

### 本地接口与文件访问边界

- **桌宠只连本机**：`pet/api.json` 里的地址必须是回环地址（`127.0.0.1` / `localhost`），否则插件拒绝连接——避免 Bearer token 被发往第三方主机。
- **配置接口防跨站**：设置、小窝、星图、桌宠代理等本地路由会校验 `Origin` 与 `Host`，跨站请求一律 403（恶意网页无法改你的开关或读你的数据）。
- **媒体展示有边界**：`companion_show_media` 只接受绝对路径，拒绝 `.ssh`/`.aws`/系统目录等受保护位置，先 `stat` 再读字节；URL 下载只允许 http(s)、逐跳校验不落到内网、限制体积与超时。
- **写入记忆的文本会清洗**：模型写入的话题名/结论统一去控制字符并限长，避免把任意文本变成下一轮的提示词。
